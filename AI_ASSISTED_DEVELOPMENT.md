# AI-Assisted Development Disclosure

3D Model Explorer was developed with substantial assistance from generative-AI coding tools.

AI assistance was used for activities including:

- exploring implementation approaches and library capabilities;
- generating and refactoring application code;
- creating and extending automated tests;
- diagnosing defects and performance concerns;
- drafting and revising documentation.

The human maintainer supplied the product direction, selected the features and tradeoffs, reviewed the repository changes, ran the verification steps, and authorized releases. AI-generated output is treated as a draft to be inspected rather than as an independent authority.

This disclosure is about development process transparency. It does not reduce the need for testing or security review, does not imply that every line was generated by AI, and does not change the project's MIT license. Bugs and security issues should be reported through the normal project channels.
